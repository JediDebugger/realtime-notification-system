# Real-time notification system

Spec: `Coding Challenge.pdf`. Summarized in docs/REQUIREMENTS.md. Never commit the PDF (public repo).

## Rules
- Build only what the spec asks. Suggest extras; don't add them unless asked.
- No implementation code until docs/ARCHITECTURE.md is approved.
- Test-first: write a failing test, then the code that makes it pass.
- Log every design decision in docs/ARCHITECTURE.md under "Decisions": the decision, alternatives considered, and why.
- When the spec is ambiguous, stop and ask. Don't pick silently.
- Must run from a clean clone with one build command and one run command.
